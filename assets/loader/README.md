# WondrPay loader

Generated by `python3 scripts/brand/make_loader.py assets/loader` from one timeline (spec: `docs/LOADER_PROMPT.md`).

| File | What |
|---|---|
| `wondrpay-loader.json` | Lottie, 512×512, transparent, 60 fps, 108 frames (1.8 s seamless loop) |
| `wondrpay-loader-reduced.json` | Reduced motion: static mark, lime dot opacity pulse (2 s loop) |
| `png@2x/wondrpay-loader_000…107.png` | 1024×1024 transparent PNG sequence, 60 fps |
| `wondrpay-loader-preview-dark.mp4` | 3 s preview on #0A0C19 |
| `wondrpay-loader-preview-light.mp4` | 3 s preview on #F4F6FD |
| `preview.html` | Open next to the JSON files to play them in lottie-web 5.12.2 |

**Timeline** (ease cubic-bezier(.65,0,.35,1)):

| Time | Motion |
|---|---|
| 0.00–1.00 s | W draws on (trim end 0→100) |
| 1.00–1.04 s | Lime dot jumps up 46 px, scale 1.15 |
| 1.04–1.10 s | Dot lands with squash (110/90) |
| 1.10–1.17 s | Dot settles |
| 1.10–1.55 s | Tile breathes 1.00→1.04→1.00 |
| 1.55–1.80 s | W un-draws (trim start 0→100) |

**Layers:** Tile (scale 78% so the glow fits in the 512 canvas; Drop Shadow effect, blue at 35%, distance 18, softness 40 px), with W and Lime dot parented to it, so everything breathes together.

**Player notes:** lottie-web renders the glow via the Drop Shadow effect. Some native players (e.g. Lottie-iOS/Skia) ignore layer effects. The mark still renders; for those, use the PNG sequence or add a static blurred glow layer.

**Usage (web):**
```html
<script src="https://cdnjs.cloudflare.com/ajax/libs/lottie-web/5.12.2/lottie.min.js"></script>
<div id="loader" style="width:96px;height:96px"></div>
<script>
  const reduce = matchMedia("(prefers-reduced-motion: reduce)").matches
  lottie.loadAnimation({ container: loader, renderer: "svg", loop: true, autoplay: true,
    path: reduce ? "/brand/wondrpay-loader-reduced.json" : "/brand/wondrpay-loader.json" })
</script>
```
The app ships a matching CSS/SVG version (`LogoLoader` in `apps/web/app/ui.tsx`), so it needs no extra library.
