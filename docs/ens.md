# ENS ($10,000)

ENS = universal pointer for addresses/identity; ENSv2 now live on Ethereum mainnet.

## Prizes
- **Best Use of ENSv2 – $7,000** (3/2/1/1). Build on ENSv2 (mainnet or Sepolia). Explore hierarchical registries, wildcard resolution off parent resolver, own subname registry, Enhanced Access Control (role-based, e.g. edit only certain text records), Permissioned Resolver per subname, record/namespace aliasing; expiring/revocable/non-transferable/"forever" subnames. Bonus: AI agents as namespaces with own identity/permissions.
- **Best Integration of ENSv2 into Existing Project – $3,000** (2/1). **Continuity only.** Must use ENSv2 on **mainnet**.

## Qualification
ENSv2 central (not cosmetic); demo functional, no hard-coded values; live demo link in showcase; open-source on GitHub.

## Fit for WondrPay
Merchant subnames (`acme.wondrpay.eth`), per-invoice/agent subnames with Permissioned Resolver holding payment text records (USDT address, chain 1874, webhook), expiring subnames for payment links, revocable agent identities (ENSIP-25/26).
